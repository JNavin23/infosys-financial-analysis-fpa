# Infosys Financial Analysis & FP&A Project

## Project Overview

This is an independent financial planning and analysis (FP&A) project based on Infosys Limited's FY2025–26 financial reporting.

The project uses Microsoft Excel to analyse historical financial performance, develop forecast estimates, evaluate budget variances, review cash flow and working capital metrics, and estimate company value using a discounted cash flow (DCF) model.

The objective is to demonstrate practical financial analysis, forecasting, financial modelling and management reporting skills.

## Project Objectives

- Analyse historical revenue, expenses and profitability.
- Evaluate revenue growth and profit margins.
- Develop a financial forecast using defined assumptions.
- Perform budget-versus-actual variance analysis.
- Identify key expense drivers and cost pressures.
- Analyse balance sheet, liquidity and working capital metrics.
- Review operating cash flow and free cash flow.
- Estimate enterprise value, equity value and implied value per share.
- Perform DCF sensitivity analysis using WACC and terminal growth assumptions.
- Present financial information through an Excel management summary and dashboard.

## Financial Modelling Approach

The project uses historical financial information as the basis for financial analysis and applies explicit assumptions to forecast future performance.

The DCF model estimates enterprise value by discounting projected free cash flows and terminal value. Cash, debt assumptions and shares outstanding are then used to estimate equity value per share.

Sensitivity analysis evaluates how changes in WACC and terminal growth affect the estimated share value.
